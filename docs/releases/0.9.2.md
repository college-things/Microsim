# Microsim 0.9.2 (beta)

## New

- Ukrainian and Russian interfaces alongside English, with live language switching in the app and native menus. Circuit text, source code, expressions and engineering units remain as authored. External tool diagnostics may remain in English.
- A unified Settings dialog: use the toolbar, File menu or Ctrl/Cmd+,. Choose system, light, dark, midnight or high-contrast themes; four accent colors; three text sizes; reduced motion; editor grid and snapping; live wire voltages; and recovery autosave delay. Save persists preferences locally, Cancel restores previous preferences, and Restore defaults keeps circuit data and the assistant key.
- PIC16F84A and PIC16F877A firmware support, assembly/HEX loading and debugger integration.
- Circuit pages and shared hierarchical blocks, with a wired multi-page example.
- PCB footprints, SMD pads, silkscreen, copper pours and a two-layer autorouter, including components across circuit pages and block instances.

## Verification

The release source passes Windows and Linux CI, including 1,278 automated tests. Browser checks cover both translations, theme previews, preference persistence and cancellation, component search, result tabs and RC simulation readings.

## macOS distribution

The universal macOS app supports Apple silicon and Intel, requires macOS 12.3 or later, and is signed through Xcode for **Khabib Bairamov (VSUKBA84LT)**. Its Apple notarization ticket is stapled to the app. The DMG and ZIP contain the verified notarized app; the DMG wrapper itself is not separately signed or notarized. `SHA256SUMS` covers the published installers and archives.

## Known limits

- This remains beta software; device models and logic levels are approximations.
- PIC EEPROM, watchdog and advanced peripherals are not implemented. Imported NI LCD/keypad parts need conversion.
- PCB thermal reliefs, island removal, manufacturing qualification and Ultiboard transfer are not implemented.
- Windows installers are not code-signed.
- See [docs/limits.md](https://github.com/college-things/Microsim/blob/v0.9.2/docs/limits.md) for the full boundaries.
