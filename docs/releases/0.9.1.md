# Microsim 0.9.1 (beta)

The second beta. Everything below is new since 0.9.0.

## New

- **Reports:** bill of materials (CSV and HTML), electrical rules check (click a finding to select its parts), SPICE and KiCad netlist export.
- **Printing:** File > Print and Export PDF, with paper size, orientation, scale and a title block (File > Title block).
- **Instruments:** frequency counter, spectrum analyzer, distortion analyzer, word generator, logic converter (truth table and minimized expression) and IV analyzer (diode, BJT and MOSFET curves).
- **Analyses:** nested and list sweeps, Monte Carlo with per-part tolerances and a histogram, worst case, harmonic distortion and two-tone IMD, noise figure, measurements, and saved batches.
- **Parts:** 47 everyday parts with original models: named transistors, diodes and LEDs, LM741/LM358/TL072/LM311, the NE555, 7805/7812/LM317 regulators, 74HC logic and the CD4017, relays, fuses, lamps, crystals, LDR and NTC sensors, push buttons and seven-segment displays.
- **Microcontrollers:** a 16x2 character LCD, a 4x4 keypad, the 8052's timer 2, and a debugger with breakpoints, pause, continue, single step and live registers.
- **Examples:** 555 blinker, 7805 supply, LCD and keypad with an 8051, logic converter, frequency counter and spectrum, word generator.
- **Web:** links like `?example=RC%20low-pass%20filter&run=1` open and run an example.

## Fixed

- Windows and Linux menus no longer show the Mac app menu; File ends with Exit.
- The serial terminal window no longer cuts off its Clear button.

## Known limits

- Windows builds aren't code-signed yet: if Windows shows "Windows protected your PC", choose More info, then Run anyway.
- PIC microcontrollers, and NI LCD and keypad parts in imported Multisim circuits, don't run yet.
- See [docs/limits.md](../limits.md) for everything else.
